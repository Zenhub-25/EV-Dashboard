# EV Market Analysis Dashboard — India 🇮🇳

An interactive EV Market Analysis Dashboard for India (2019–2023), built as a consulting-style project.

## 🌐 Live Demo
👉 [View Dashboard](https://ev-market-dashboard-india.vercel.app)

## 📊 Features
- 5 interactive charts (Chart.js) — Sales trends, Segment share, Charging infrastructure, Company share, YoY growth
- 4 KPI cards with animated counters
- 8 consulting-style market insights (FAME II, battery costs, 2030 outlook)
- Business analysis framework (Trends, Drivers, Challenges, Opportunities)
- Raw datasets — copy directly to Excel
- Fully responsive dark-theme UI

## 📁 Project Structure
```
├── index.html    → Dashboard structure & layout
├── style.css     → Dark theme, animations, glassmorphism
├── app.js        → Chart.js charts + interactive filters
└── vercel.json   → Vercel deployment config
```

## 🛠️ Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Chart.js 4.4 for visualizations
- Google Fonts (Inter + Outfit)
- Deployed on Vercel

## 📈 Data Sources
- VAHAN Portal (MoRTH)
- NITI Aayog EV Reports
- SMEV (Society of Manufacturers of Electric Vehicles)
- FAME II Policy Documents
